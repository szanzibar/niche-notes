# niche-notes — v1 spec

## Problem

Amplenote is a paid subscription, its sync has lost data, and it is cluttered. We want a scratch pad for a family of two or three: pop open a phone, jot a note or a list, find it later, and edit the same shopping list together.

## What v1 does

- **Notes in a tree.** Any note can hold notes. There are no folders and no notebooks. New notes go on top. Every row has a + for a note inside it. Drag a note onto the middle of another to nest it, onto its top or bottom edge to sit next to it, or onto the header to bring it back to the top. A line shows where it will land, indented the way it will be. On a touch screen every row has a grip on its left that drags at once, like the lines in a note. With a keyboard, Shift and a click pick every row from the last one clicked to that one, and Ctrl or ⌘ and a click pick or drop a single row. Picked rows wear the accent, and dragging one of them moves them all, in the order they were in, each with the notes under it. A plain click opens its note and lets the rest go. A folded row stays folded on every device of yours. Back from a note returns to the tree, even when a widget, a calendar event or an alert opened the note, and back again leaves the app. A clock in the tree's footer opens a Recent section above it with the notes last opened on that device, the last one first and without the open note, so the note before is one tap away. It stays open or closed per device.
- **Pins.** A pinned note sits above its siblings, at the top level or inside its parent. Pins are ordered among themselves by dragging, and a drop never pins or unpins a note. A new pin goes below the other pins, and an unpinned note goes on top of the rest.
- **Search.** The box at the top of the tree filters as you type, title matches first, then text, each with the words around the hit. While it has text, two buttons beside it choose whether the trash and checked lines count. The trash does and checked lines don't, until the person changes that, and the choice follows them to every device. Trashed notes are marked. The open note is highlighted like its row in the tree. Arrow keys and Enter open a result on a keyboard, and the arrows go on from the open note. It works offline, since every note is on the device. The box always shows a clear button while it has text.
- **One editor.** A title field and a body with three heading levels, code blocks, quotes, dividers, bold, italic, strikethrough, inline code, links, highlight, bullet lists, numbered lists, checkbox lists and tables. Two lists of one kind that touch are one list, so only a blank line keeps them apart. A checked item is crossed out. Ticking a box never moves the note: while typing, the cursor goes to the end of that line, and otherwise the keyboard stays down. In a note set to hide them, it hides once it and every item under it are checked, for everyone and in its widgets. Checked items wait until the note has been still for five seconds, then fold away together, so ticking down a list never moves the next box. A note set to delete them hides them the same way and deletes them the next time it opens. A checkbox button beside the title opens Hide checked, Delete when checked, Uncheck all and Delete checked in a box under it, and a tap anywhere else closes it. Every box a button opens floats beside that button, over the note. Uncheck all clears every box, so a packing list can be used again. Delete checked removes the items that would hide, showing them for a moment first when they are hidden, and its button shows a checked box going into the trash. A tap on a link puts the cursor in it, and its address in a box under it opens it. Every list line has a grip in the margin, shown all the time on a touch screen and for the line under the pointer otherwise. Dragging the grip moves the line with everything nested under it. Like a note in the tree, it lands above the line it is dropped on from the top of that line, below it from the bottom, and as its first child from the middle. The drag looks like one in the tree: the line rides as a box with its text, a row above a finger, its place stays dimmed, the line it goes into is outlined, and a line shows where it will land, indented the way it will be. A line dropped into another kind of list takes that list's kind. Dropping it on a note in the tree moves it there. A tap on the grip asks which note to move it to, and the line lands at the end of that note, in its list when the note ends in one. Headings and paragraphs drag by a handle that shows beside them. A tap toolbar does all of this on every platform, and markdown shortcuts work too (`- `, `1. `, `[] `, `# `, `> `, `---`). Opening a note puts the cursor in it: an empty title first, otherwise where this device last left the cursor, or the end of the text. A widget opens its note with the keyboard up, whether the app was running or closed. Enter or Tab moves from the title into the body. Undo history stays with the note while the app is open.
- **Tables.** The toolbar's table button adds one with a header row, and while the cursor is in a table its tools sit beside that button: add a row, add a column, delete a row, a column or the table, each at the cursor. Return moves to the next cell, so a phone keyboard fills a row, and Return in the last cell adds a row. Return in an empty last row removes it and leaves the table, the way it leaves a list. Cells hold plain text, and a table wider than the note scrolls sideways. A widget shows each row as one line.
- **Dates and alerts.** A checkbox line can have a date, a time and a repeat. The date button in the toolbar sets them in a box that stays open until a tap elsewhere, and so does a tap on the date at the end of the line. Today, Tomorrow and Next week are one tap, and a line with a time can last 15 minutes to 3 hours in the calendar. A line that gets a time lasts as long as the last length the person picked, on any device, and half an hour until they pick one. A date can be typed into the line too, in English: today, tomorrow, next week, a weekday, a day like nov 20, a time like at 5pm or 17:00, and every day, every weekday, every other monday, or every week, month or year. The words wear the accent color while the cursor stays on the line, and the line's date shows what they make, with an ✕. Leaving the line, the note or the app turns them into the line's date and takes them out of the text. A tap on that date or Escape keeps them as words, and afterwards Undo brings them back. Typed onto a line that has a date, they change only what they say. Only words just typed count, so a line that already says Sunday roast stays as it is, and so does a line that is nothing but a date. A line repeats every week on chosen weekdays (all seven is every day), every month on a day of the month or on the 1st to 4th or last of chosen weekdays, or every year, each every one or more weeks, months or years apart, and the box says the rule in words. The box shows the weekday beside the date, and its weekdays start on Monday. Dates and times follow the device's language settings. The date reads Today, Tomorrow, a weekday within the week, or the date itself, and turns the accent color once it is overdue. Ticking a repeating line moves it to its next date instead of checking it. When a line comes due, everyone on the note gets an alert at its time, or at 9:00 when it has none, in each device's own time zone. A repeating line alerts on each of its days until someone ticks it, so a missed day doesn't silence the next. The alert's Done ticks the line, Snooze 1 hour moves it to an hour later, and a tap opens the note at the line. Settings says whether alerts are on for the device, and turns them off there and back on, as for a browser on a computer whose desktop app alerts too. The desktop app shows alerts whenever it runs, with its window open or closed, and a click on one opens the note at the line. It also connects Google Calendar, which puts a Niche Notes calendar in the person's own Google account. That calendar shows every dated line they can open, a minute after each change, and each event links to its line in the note. Changes go one way, so edits happen in Niche Notes.
- **Due.** A calendar button beside the search box counts the unchecked lines due today or earlier, in every note outside the trash. It is there while any line has a date. A tap lists the dated lines in place of the tree, in Past due, Today, Tomorrow and Later sections, under their notes, the note with the oldest line first, each with its date, in the accent color once it is overdue. Each section folds, and stays folded for that person on every device. A tap on a line opens its note with the cursor at the end of that line. It works offline, and for notes that were never opened on the device.
- **Private by default.** A note is visible only to its owner until the owner shares it with a specific person. Sharing grants full edit access to that note only, not to its children. The person it is shared with gets a notification saying who shared which note, on every device where they turned on alerts, and a tap opens it. The owner can also make a link that lets anyone edit the note without an account: whoever opens it gets the note under a made-up name like Teal Otter, and turning the link off takes it away from them again. A guest has that note and nothing else: no notes of their own, and nobody's name but its owner's. Share is an outline of two people on a private note, and filled with the number of people once it is shared, so a shared note in the tree wears the filled icon too, like a pinned note's pin.
- **Your tree is yours.** Sharing a note does not move it. It appears at the top of the other person's tree, under their pins, and they drag it wherever they like. A note someone else owns shows their first name wherever it is listed. Its header has the filled people icon with an arrow coming in where the owner has Share, and a tap on it says who shared the note. A Leave button in place of Delete moves it to their own trash, where Restore brings it back and Leave for good drops the share for them alone. The owner's note is never touched.
- **Offline first.** Everything except sharing works without a connection: create, edit, move and delete, including notes shared with you. Changes merge when the connection returns. A crossed-out cloud in the header says when the server can't be reached.
- **Real time.** Two people editing one note see each other's keystrokes and cursors. A cursor shows with its person's first name, or a guest's whole made-up name, while that person moves it, and goes after five seconds of stillness.
- **Trash, not confirmations.** Delete is one tap. A note with notes under it asks first, on Delete or Leave, whether they go too. Alone, they move up to its parent. With it, they go to the trash as one entry, which Restore and Delete forever act on whole. The note goes to a Trash section at the bottom of the tree, where it can be read but not edited, restored, or deleted forever. A note restored while the note above it is still in the trash comes back at the top. Anything in the trash for thirty days is deleted for good, by the client the next time it starts and catches up with the server, so no server job is involved.
- **Settings.** Light, dark or follow-the-device appearance, a Default or Confetti color scheme, a theme of fourteen colors under Default, and a compact, default or large density. The theme's color fills the note header and the selected row and tints the page and the tree, and it stays readable in light and dark. All but density follow the user to every device, and density stays with each device, since a phone and a desktop want different sizes.
- **Note colors.** A palette button in a note's header picks its color, and that note then wears it under either scheme. Under Confetti a note without one gets a color from its id, and the whole app wears the open note's color. With no note open it wears the last note opened on that device, or the top note. Colors are each person's own, so on a shared note each person sees their own. A note with a color shows it as a stripe beside its grip in the tree, moving in with its nesting.
- **Note header.** The actions sit beside the title until it would be cut off or they no longer fit on its row. Then they all fold behind dots that reveal them under the title, and the title ends in "…". Share stays beside the dots, or the shared icon on a note someone else owns, and so does the crossed-out cloud when offline. Share, or the shared icon, comes first among the actions.
- **Widgets.** On Android, two kinds of home-screen widget, any number of each, 2×3 when added. A note widget shows a whole note you pick, read-only, with headings in bold and blank lines kept, under a header in the color the note wears for you. Adding or reconfiguring one opens the tree to pick from, and tapping it opens the note in the app. An All notes widget shows your tree as you folded it, and a tap on a note there opens it. Adding one opens the app just long enough to hand it your tree. Widgets refresh every 30 minutes and from a refresh button.
- **Native.** An Android app, a desktop app for macOS and Windows, and the web app, which Chrome and Edge install as an app too, all loading the same build from the server. The Android app shows its icon the moment it is tapped, until Chrome opens the page. It updates itself from the project's releases: it downloads a newer one in the background and offers to install it on the next launch. The desktop app signs in through the default browser, where the passkey works. Closing its window leaves it in the tray, where a click opens the window again and the menu quits it. It starts at login, and it updates itself while its window is closed.
- **Self-hosted.** One Docker container and one SQLite file. Login through Pocket ID passkeys, and a session lasts a year past the last launch. Sign out takes the notes off the device, and the next login asks which account to use instead of signing the same person back in. A person can be shared with once they have logged in. A backup of the file restores by putting it in place and starting the app, or runs as an offline copy to look at, and after a restore each device sends back whatever the backup lacked.

## Not in v1

Markdown export, sharing a note with its children, images and attachments, iOS, view-only sharing.
